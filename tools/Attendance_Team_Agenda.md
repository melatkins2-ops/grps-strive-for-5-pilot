# Attendance Team Agenda

1. Review schoolwide patterns and positive outliers.
2. Identify scholars requiring targeted review.
3. State the primary WHY: Barrier / Aversion / Disengagement / Misconception.
4. Select one coherent matched intervention and owner.
5. Review fidelity, barrier reduction, and attendance response.
6. Decide: Continue / Adjust / Fade / Intensify.
7. Escalate repeated barriers into school/system action.
