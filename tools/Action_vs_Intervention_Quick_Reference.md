# Action vs. Intervention Quick Reference

**Action:** something staff did (call, letter, referral, resource link, conference). It is not, by itself, an intervention.

**Intervention:** an intentional response designed to remove/reduce the identified barrier, change a condition/behavior, build a needed skill/relationship, or otherwise address the documented reason for absence.

Document: root cause, intervention, owner, dosage/frequency, fidelity evidence, barrier-reduction evidence, attendance response, and 10/20/30-day decision.
